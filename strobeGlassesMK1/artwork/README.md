# PCB artwork

`eye-fragments.svg/json` contains the current rear illustration: cropped gazes woven into exposure ribbons, with shutter slits inside the irises. The caption **YOU CAN SEE EVERYTHING** is separate, editable KiCad text.

`rivercraft.svg/json` and `strobeglasses.svg/json` contain the front wordmarks. The PCB embeds the fitted artwork as native silkscreen polygons; SVG/JSON coordinates are millimetres.

The original portrait was generated from supplied documentary reference images, then converted and composed as vectors. References: [You Can See Everything](https://a24films.com/films/you-can-see-everything) and [the meme](https://knowyourmeme.com/memes/elizabeth-holmes-and-nathan-fielder-why-would-i-deceive-you). Small tapered details may simplify in physical silkscreen.
